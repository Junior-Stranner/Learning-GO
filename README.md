# Learning GO

Repositório de estudos pessoais da linguagem Go. Estou aprendendo do zero por meio de aulas e exercícios diários, documentando minha evolução ao longo do tempo.

## Sobre o projeto

Este repositório reúne todo o material prático da minha jornada de aprendizado com Go — desde os fundamentos da linguagem até conceitos mais avançados como concorrência, APIs e boas práticas de desenvolvimento backend.

Os exercícios são organizados por dia/tema, acompanhando o progresso das aulas.

## Estrutura do projeto

```
Learning-GO/
├── main.go                        # Ponto de entrada principal
├── go.mod                         # Módulo Go
├── exercises/
│   ├── dia01-fundamentos/         # Variáveis, tipos, constantes
│   ├── dia02-controle-fluxo/      # if, for, switch
│   ├── dia03-funcoes/             # Funções, múltiplos retornos
│   ├── dia04-arrays-slices/       # Arrays, slices, maps
│   ├── dia05-structs/             # Structs e métodos
│   ├── dia06-interfaces/          # Interfaces e polimorfismo
│   ├── dia07-goroutines/          # Concorrência com goroutines
│   └── ...
```

## Como rodar um exercício

Cada pasta de exercício é independente e pode ser executada diretamente:

```bash
go run exercises/dia01-fundamentos/main.go
```

## Tópicos de estudo

- [ ] Fundamentos — variáveis, tipos, constantes
